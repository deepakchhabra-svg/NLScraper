🚀 QUICK START (3 Steps)
================================================================================

1. Install Dependencies:
   pip install -r requirements.txt

2. Run the Scraper:
   python main.py

3. Check the Output:
   - CSV files will be in: output/
   - Images will be in: images/
   - Logs will be in: logs/

That's it! The scraper will start extracting product data from Noel Leeming.

================================================================================
⚙️ BASIC COMMANDS
================================================================================

# Standard run (full scrape)
python main.py

# Test run (10 products, no images)
python main.py --max-products 10 --no-images

# Fast run (no images)
python main.py --no-images

# Excel output instead of CSV
python main.py --format excel

# Increase delay (more respectful)
python main.py --delay 5

# Verbose logging (for debugging)
python main.py --log-level DEBUG

# Resume from checkpoint (automatic)
python main.py --resume

================================================================================
📁 WHAT GETS CREATED
================================================================================

After running, you'll have:

output/
  ├── noel_leeming_products_TIMESTAMP.csv        (Main data)
  └── noel_leeming_products_trademe_TIMESTAMP.csv (TradeMe format)

images/
  └── [Downloaded product images]

logs/
  └── scraper.log (Detailed logs)

checkpoints/
  └── scraper.checkpoint (Resume point)

================================================================================
🎯 TRADEME UPLOAD
================================================================================

1. Run the scraper
2. Find the TradeMe CSV in output/
3. Open the file to verify data
4. Manually upload to TradeMe using their import tool

The TradeMe CSV has the following columns ready for upload:
- Title, Category, Description
- StartPrice, BuyNowPrice
- Photos, Condition, ShippingInfo
- SKU

================================================================================
⚠️ IMPORTANT NOTES
================================================================================

ETHICAL SCRAPING:
- Default delay: 2 seconds between requests
- Respects robots.txt
- Automatic throttling
- Don't reduce delays too much

INTERRUPTIONS:
- Press Ctrl+C to stop
- Progress is saved automatically every 50 products
- Run again with --resume to continue

FIRST RUN:
- Test with: python main.py --max-products 5 --no-images
- Check output files are correct
- Then run full scrape

WEBSITE CHANGES:
- If website structure changes, selectors may need updating
- Check scraper.py for selector lists
- Update as needed based on actual website
